# NoteShare

A mobile application designed for college students to upload, explore, bookmark, and share study notes.

## Tech Stack
- React Native
- Expo
- Node.js
- Express.js
- MongoDB (planned)

## Features
- Login and signup interface
- Explore and search notes
- Upload PDF and image notes
- Bookmark notes
- View uploaded notes
- User profile

## Project Status
Frontend implemented with local mock data.
Backend integration is in progress.

## Project Structure
- `client/` — React Native mobile application
- `server/` — Backend application
